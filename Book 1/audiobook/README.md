# The Watch Below — audiobook scripts

AI-ready narration scripts for *The Watch Below*, Winshire Chronicles Book One.

## Contents

- `Scripts/`: opening, chapter scripts, and closing in SSML with AI performance comments and pause cues.
- `AI_Narration_Instructions.md`: how an AI narrator should interpret cues and pauses.
- `Synthetic_Voice_Brief.md`: concise delivery brief.
- `Pronunciation_Guide.md`: provisional pronunciation cues.

The `AI CUE` XML comments are directions, not spoken text. Preserve the story wording exactly.
